## 1. 重大發現（2026-05-03 → 2026-05-04）

### 1.1 OOF/LB gap 真因 = CV protocol bias（不是 distribution shift）

過去用 `StratifiedKFold(shuffle=True, random_state=SEED)` 對 14995 rallies 切。問題：rally-level KFold 在 train fold / val fold 間保留 **~99% player overlap**。OOF metric 量到的是「在見過的選手身上的 performance」，不對應 test 的 46% unseen player + 100% match-disjoint 條件。

**驗證實驗**（`src/train/match_disjoint_lgb.py`）：
- LGB rally-KFold OOF: action F1=0.3897, point F1=0.2272
- LGB match-disjoint OOF: action F1=0.3023 (-0.087), point F1=0.1836 (-0.044)
- **Δ_CV = -0.0524**（與實際 OOF/LB gap -0.053 幾乎一致）

→ 整個 OOF/LB gap **完全由 CV protocol bias 解釋**，cross-event drift 是 secondary。

### 1.2 v5z_md (match-disjoint full) 結果

LSTM + LGB 都用 `StratifiedGroupKFold(N=5, groups=match_id)` 重訓。

| metric | rally-KFold (baseline V5Z bag2) | **match-disjoint (v5z_md bag2)** |
|---|---|---|
| OOF CV calibrated | 0.4816 | **0.4414** |
| LB | 0.4285 | **0.4374** |
| OOF/LB gap | **-0.0531** | **-0.0040** ✅ |
| α_action | 0.64 | **0.85** (LSTM dominant) |
| α_point | 0.50 | **0.98** (almost pure LSTM) |

**意涵**：match-disjoint trained LSTM 學會 cross-event robust player embedding。LGB（含手工 player IDs / cross-event biased features）在 cross-event 條件下幾乎無貢獻。

### 1.3 Bag3 with s100 確認不會 dilute

Rally-KFold bag3 with s2024 失敗（s2024 single CV 0.4765 偏弱）。Match-disjoint 的 s100 single CV ≈ 0.4361（與 s42=0.4361, s1337=0.4363 同水準），不 dilute。

bag3 (s42+s1337+s100) calibrated CV = **0.4441** (+0.0027 vs bag2)。

→ 已生成 `submissions/submission_v5z_md_advcal_bag3.csv`，明日 Sub 1 候選。
