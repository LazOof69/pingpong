## 2. 3-Step Execution Plan

### Step 1（明日早上，2-4h）— Random-prefix truncation augmentation

**Why first**：唯一直接打到我們**已診斷確認**的 root cause（OOF/LB divergence = 0.463）。Claude #1 估算 +0.025~0.060 LB，遠高於其他選項。5 行 dataloader 改動，60 分鐘 kill criterion。

**實作骨幹**：
```python
# In dataloader for each rally (L, target_at_L):
TEST_L_DIST = {1: 0.32, 2: 0.24, 3: 0.16, 4: 0.12, 5: 0.16}  # match test histogram
k = sample_from(TEST_L_DIST)
prefix = strokes[:k]
target = stroke_at_{k+1}
features = recompute_lgb_features(prefix)  # CRITICAL: not on full rally
# Add to LSTM input: step_idx=k, is_truncated=True
# Add to LGB: step_idx, is_truncated columns
```

**1-hr kill criterion**:
- After 1 epoch, length-matched OOF AUC must drop from 0.819 to **0.65~0.75**
- If stays at 0.819 → truncation **沒套進去**（最常見 bug：LGB feature 仍在 full rally 上算）
- If drops below 0.55 → 截斷分布太激進，調 P(k) 配比
- If neither happens within 60 min → BiLSTM directionality 洩漏 full state，**換 causal LSTM**

**Expected**: LB 0.3564 → **0.381~0.416**

**Ship CSV**: `submissions/submission_v5z_md_advcal_bag2_PREFIX.csv`

### Step 2（明日下午，4h）— Logit Adjustment + 20-sweep calibration

**Gate**: Step 1 LB lift >= +0.005（kill: 若 <0.005，先 debug Step 1，不上 Step 2）

**Why second**：與 #1 機制正交（#1 修 input distribution，#2 修 loss landscape）。F1 components 是 LB 2× weight per unit，本路線專攻 F1。

**實作**：

```python
# Training time:
log_prior = torch.log(class_freq / class_freq.sum())
loss = F.cross_entropy(logits + tau * log_prior.unsqueeze(0), targets)
# tau ∈ {0.5, 1.0, 1.5} grid-searched separately for action and point heads

# Inference:
# DROP adjustment, predict from raw logits
preds = logits.argmax(-1)

# Calibration (replace single-pass plug-in bias):
for sweep in range(20):
    for c in range(num_classes):
        # grid-search additive bias b_c ∈ [-3, 3] in 121 steps
        # holding other classes fixed
        b[c] = argmax_macro_F1(b)
```

**1-hr kill criterion**:
- Rarest 5 action+point classes F1 must improve **>= 30% relative** within one epoch
- If < 10% → log_prior signal 太弱，調 tau
- If 0% → log_prior 算錯（最常見：用 train 全 N 算的 prior，但 test 是 truncated → 用 truncated prefix prior 重算）

**Expected**: F1_action 0.371→0.395-0.410, F1_point 0.224→0.245-0.255, composite +0.012-0.025
**LB lift on top of Step 1**: +0.012~0.025

**Ship CSV**: `submissions/submission_v5z_md_advcal_bag2_PREFIX_LA.csv`
**Sub credit**: 2/3 (明日)

### Step 3（後天，6-8h）— ShuttleSet cross-sport pretraining

**Gate**: Step 1+2 cumulative LB lift >= +0.020（不夠則改 LA hyperparam sweep / dual-stream encoder）

**Why third**：最大投資、最高 variance、但唯一「真正引入新 information」的路線。三家 AI 共識 + peer-reviewed validation（Hsu 2026 MJSSM）。

**Resource**:
- ShuttleSet: `github.com/wywyWang/CoachAI-Projects/tree/main/ShuttleSet`
  - 3,685 rallies / 36,492 strokes / 27 players
  - schema overlap ~85%（shot_type, landing_area, getpoint_player, lose_reason, height）
- ShuttleSet22: `arXiv:2306.15664`
  - +3,992 rallies / 33,612 strokes
  - **L=4 truncated 4-stroke prefixes** — 最接近我們 L=3.07
- 合計 ~70k strokes，比擬我們 84,707 strokes

**實作四階段**:

1. **Spatial normalization**: φ(x,y) = (x/W, y/L) → [0,1] × [0,1]
2. **Latent tactical taxonomy mapping** (badminton 18 cls ↔ TT 19 cls):
   ```
   net-shot/return-net/cross-court-net-shot → short_push
   smash/wrist-smash → smash
   lob/defensive-return-lob → lob
   clear → drop
   drive/back-court-drive → drive/fast-drive
   drop/passive-drop → drop-shot
   push/rush → push/flick
   short-service / long-service → serve_X
   ```
3. **Pretrain BiLSTM** (hidden 128-256, 2 layers) with 3 heads:
   - next-stroke 22-class CE
   - landing 9-zone CE
   - "did server win the rally" BCE
   - **uses prefix-truncation sampling from Step 1**
4. **Fine-tune on TT**:
   - Restore body, reinitialize task heads (output cards differ: 22→19, 9→10, BCE stays)
   - Reinitialize embedding rows for TT-only classes (twist, chop, fast-push, pimples-push)
   - AdamW lr=1e-4 body / 1e-3 heads, 5-10 epochs, prefix-sampling on
   - Extract LSTM hidden as 128-d LGB features

**1-hr kill criterion**:
- After 1 epoch badminton-only pretraining, ShuttleSet22 truncated val next-stroke top-1 must reach **>= 0.30** (CoachAI Challenge 2023 baseline)
- If <= 0.10 → schema mapping 錯（最常見：類別對應錯，少見：嵌入維度不一致）
- If 0.10~0.20 → 收斂太慢，加 epoch 或調 lr

**Expected**: +0.005~0.020 LB

**Ship CSV**: `submissions/submission_v5z_md_advcal_bag2_PREFIX_LA_SHUTTLE.csv`
**Sub credit**: 1/3 (後天)
